# Repository guidance

## Purpose

This public repository owns Daryl Kang's GitHub profile README and GitHub-native
identity. The root README is profile content, not repository setup documentation.

## Working principles

- Keep the profile concise and include only accurate, approved public information.
- Do not publish private plans, internal repository details, credentials, or secrets.
- Keep this repository lightweight; website application code belongs elsewhere.
- Keep initialization minimal. Add directories, dependencies, and workflows only
  when required by the work at hand.

## Verification and commits

- Match verification to the changed behavior. For documentation-only changes,
  check accuracy, links, and the diff; this repository has no application test suite.
- Use Conventional Commits with concise, imperative subjects and coherent scope.
- Keep credentials and unrelated changes out of commits. Push or publish only
  within the user's authorized delivery scope.
